🛡️ 如何防止 DNS 泄露和 WebRTC 泄露
1️⃣ 在 Clash 中开启 fake-ip 或 redir-host 模式：这可以将所有 DNS 请求都走代理，避免 DNS 泄露到本地运营商。
2️⃣ 使用 TUN 模式（系统代理）：Clash Verge Rev、Mihomo Party 的 TUN 模式可接管所有流量，包括不支持代理的应用程序，彻底防止泄露。
3️⃣ Chrome/Edge 关闭 WebRTC：安装 "WebRTC Leak Prevent" 扩展，或访问 chrome://flags/#disable-webrtc-hide-local-ips-with-mdns 修改设置。
4️⃣ Firefox 禁用 WebRTC：地址栏输入 about:config，搜索 media.peerconnection.enabled，设为 false。
❓ 什么是 DNS 泄露，为什么危险？
🔍 DNS 请求未经代理：当您访问 google.com 时，如果 DNS 查询走了国内运营商的服务器，运营商就知道您在访问 google.com，即使实际数据通过代理传输。
⚠️ WebRTC 可绕过 SOCKS5/HTTP 代理：浏览器的 WebRTC 功能会直接使用本地网络接口获取 IP，即使已连接代理，真实 IP 也可能被网站检测到。
✅ 正常情况：WebRTC 检测只看到您代理出口的 IP；DNS 请求通过代理的 DNS 服务器解析，不经过本地 ISP。
