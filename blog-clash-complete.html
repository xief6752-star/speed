Clash 完整配置教程 2026：从下载到分流一次搞定

Windows 配置（Clash Verge Rev）

第一步：下载安装

前往 Clash Verge Rev 教程页 获取官方下载链接。Windows 用户下载 .exe 安装包，双击按提示安装即可。

第二步：设置语言

首次打开可能是英文界面，进入 Settings → General → Language，选择 zh-CN，重启软件生效。

第三步：导入机场订阅

① 登录机场后台，复制「Clash 订阅链接」（通常在「使用说明」或「一键订阅」里）。

② 打开 Clash Verge Rev，点击左侧「订阅」→ 右上角「导入」，粘贴链接 → 点击保存。

③ 等待软件自动下载并解析节点列表。

⚠️
常见错误：订阅链接粘贴后点击导入没有反应？检查是否多了空格，或尝试关闭软件重新打开后导入。

第四步：选择节点 + 测速

点击左侧「代理」面板，顶部确保选择「规则」模式。点击右上角测速按钮（雷电图标），等待几秒出现延迟数字后，选择延迟最低的绿色节点。

第五步：开启系统代理

回到「设置」，找到「系统代理」开关，打开。状态栏图标变色后即可正常上网。

进阶：TUN 模式

如果需要代理游戏、终端（cmd/Terminal）等不走系统代理的程序，在设置中开启「TUN 模式」，点击安装服务模式（需要管理员权限），然后开启 TUN 开关。

macOS 配置（Clash Verge Rev）

macOS 版 Clash Verge Rev 配置步骤与 Windows 基本相同：下载 .dmg 文件 → 拖入应用程序 → 打开 → 导入订阅 → 开启系统代理。

注意：首次开启系统代理时，macOS 会弹出「允许更改网络设置」的确认框，点击「好」并输入开机密码即可。

常见问题

开了代理但 YouTube 还是打不开？

检查：① 代理模式是否为「规则」而非「直连」；② 所选节点是否有延迟数字（无数字 = 超时 = 不可用）；③ 尝试换同地区其他节点。

国内 App（微信/淘宝）变慢了？

代理模式误设为「全局」，改回「规则」模式即可，国内流量会自动直连。

订阅更新失败？

① 先关闭代理再更新订阅（避免死锁）；② 登录机场后台重新复制最新订阅链接覆盖旧链接。

✅
配置完成检验：打开浏览器访问 https://www.google.com，能正常加载说明配置成功。如仍无法访问，检查上述步骤是否有遗漏。
